# Beauty of Bharat — Claude Code build kit

1. Unzip this folder and open it in Claude Code (or copy its contents into an empty project folder).
2. Open CLAUDE_CODE_PROMPT.md and paste everything below the line into Claude Code.

Contents
- CLAUDE_CODE_PROMPT.md — the full build brief
- brand/ — logo and mark as clean SVGs (colour, white, black), made from your Illustrator PDF
- design-reference/ — the approved UI screens (Home, Article, People, Profile, About, Contact, MobileHome, MobileArticle).
  These are reference markup from the design tool. Claude Code reads them for exact styles; they won't fully render if opened directly in a browser.
